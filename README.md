# Target1900 randum tester

ターゲット1900の単語からランダムに単語テストを作って、A4で印刷できる Web アプリです。

## 使い方

1. **範囲** を選ぶ（1〜1900 の単語番号）。下のリストにその範囲の単語が番号順に並びます
2. **問題数**（1〜200）を決める
3. **形式** を選ぶ
   - `Aあ` … 英語を見て意味を書く
   - `あA` … 意味を見て英語を書く
4. 「テストを作成」→ 印刷プレビューで **問題 / 答え** と **組** を選んで「印刷する」

印刷ダイアログでは **用紙 A4・余白なし・倍率100%** を選んでください。

URL に設定と乱数シードが入っているので、同じ URL を開けば同じテストを再現できます。

## 開発

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run lint
```

## 単語データ

`ターゲット1900.xlsx`（番号 / 単語 / 意味）が元データです。次のコマンドで
`src/data/target1900.json` を生成し直せます。

```bash
npm run build:words
```

意味は「；」区切りで複数の語義が入っているため、印刷時は先頭の語義だけを使い、
`（⇔ ... ⇒ 123）` のような参照表記は落としています（`src/lib/words.ts` の
`primaryMeaning`）。

## 組と枚数

- **1 組 = 問題用紙 1 枚 + 答え用紙 1 枚**、A4 縦 1 枚あたり 28 問（14 行 × 2 段）固定
- そのため **組数は問題数から決まります**（`ceil(問題数 / 28)`）。組数の設定項目はありません
  - 例）84 問 → 3 組 6 枚 ／ 100 問 → 4 組 8 枚（4 組目は 16 問）
- 同じ組の問題用紙と答え用紙は同じ組番号になります（1 組目ならどちらも「1枚目 / 3」）
