# tango random tester

単語帳からランダムに単語テストを作って、A4で印刷できる Web アプリです。

対応単語帳:

- 英単語ターゲット1900 6訂版
- 英検2級 でる順パス単 5訂版
- 英検準1級 でる順パス単 5訂版

## 使い方

1. **単語帳** と **範囲**（単語番号）を選ぶ。下のリストにその範囲の単語が番号順に並びます
2. **出題形式** を選ぶ
   - `ENから日本語` … 英語を見て意味を書く
   - `日本語からEN` … 意味を見て英語を書く
3. 「テストを作成」→ 印刷プレビューで **ランダム抽出する問題数** と **1ページあたりの問題数（25 / 50）** を決め、**問題 / 答え** を選んで「印刷（PDF）」

URL に設定と乱数シードが入っているので、同じ URL を開けば同じテストを再現できます。

## 開発

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run lint
```

## デプロイ

Vercel の "Import Git Repository" でこのリポジトリを選ぶだけで動きます。フレームワークは
Next.js が自動検出され、環境変数もビルド設定の変更も要りません。

## フォント

- 本文は **Gen Interface JP**、数字は **Google Sans Flex**
- ロゴ「tango random tester」は **Yikes** をパス化した SVG（`public/brand-yikes.svg` / `brand-yikes-stacked.svg`）

## 単語データ

`ターゲット1900.xlsx`（番号 / 単語 / 意味）がターゲット1900の元データです。次のコマンドで
`src/data/target1900.json` を生成し直せます。

```bash
npm run build:words
```

出力は `[英単語, 意味]` のペアの配列で、配列の位置 + 1 が単語番号です。

意味は元データだと「；」区切りで複数の語義が入っていてマス目に収まらないため、変換時に先頭の
語義だけを残し、`（⇔ ... ⇒ 123）` のような本の中でしか意味がない参照表記を落としています
（`scripts/build-words.mjs` の `primaryMeaning`）。全語義が必要になったらこの関数を外して
生成し直してください。

パス単のデータは `src/data/pass2.json` / `passPre1.json` を直接編集します。

## セットと枚数

- **問題数はランダムに出題する全問題数**で、それを 1 ページあたり 25 問または 50 問のセットに分けます
- **1 セット = 問題用紙 1 枚 + 答え用紙 1 枚**（A4 縦）
- セット数は `ceil(問題数 / 1ページあたりの問題数)` で決まります
