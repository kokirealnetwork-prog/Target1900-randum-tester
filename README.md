# Target1900 randum tester

ターゲット1900の単語からランダムに単語テストを作って、A4で印刷できる Web アプリです。

## 使い方

1. **範囲** を選ぶ（1〜1900 の単語番号）
2. **問題数**（1組あたりの出題数）と **組数**（何パターン作るか）を決める
3. **形式** を選ぶ
   - `Aあ` … 英語を見て意味を書く
   - `あA` … 意味を見て英語を書く
4. 「テストを作成」→ 印刷プレビューで **問題 / 答え** と **組** を選んで「印刷する」

印刷ダイアログでは **用紙 A4・余白なし・倍率100%** を選んでください。

同じ設定でも組ごとに違う並び・違う単語が選ばれるので、そのままクラス分の別パターンを作れます。URL に設定と乱数シードが入っているので、同じ URL を開けば同じテストを再現できます。

## 開発

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run lint
```

## 単語データ

`ターゲット1900.xlsx`（番号 / 単語 / 意味）が元データです。次のコマンドで
`src/data/target1900.json` を生成し直せます。

```bash
npm run build:words
```

意味は「；」区切りで複数の語義が入っているため、印刷時は先頭の語義だけを使い、
`（⇔ ... ⇒ 123）` のような参照表記は落としています（`src/lib/words.ts` の
`primaryMeaning`）。

## 印刷レイアウト

- A4 縦 1 枚あたり最大 28 問（14 行 × 2 段）
- 1 組が 28 問を超えると自動で複数枚に分割し、各ページに均等に配分
- 「問題」用紙と「答え」用紙をそれぞれ出力（答えの用紙は問題と答えが両方入った答案例）
